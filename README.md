# storm-env

Utilities and scripts for managing development environments and related tasks.

This repository contains Shell and Lua scripts (see the language composition: Shell ~58%, Lua ~42%). Use the scripts in this repo to automate environment setup and small utilities.

## Contents

- Shell scripts: for installation, setup, and automation.
- Lua scripts: utility scripts and helpers.

## Getting started

1. Clone the repository:

   git clone https://github.com/0ncoming-Storm/storm-env.git
   cd storm-env

2. Inspect the scripts and run the ones you need. For example, make scripts executable and run:

   chmod +x ./script.sh
   ./script.sh

Replace `script.sh` with the script you want to run.
